# Marca de Prizma

**Decisión del 15 de noviembre de 2026:**
- **Nombre:** Prizma.
- **Logo:** el mosaico cuadrado **M1, «Uno distinto»** (`mosaico/mosaico-M1.svg`): una grilla de 3×3 donde una tesela es redonda. La auditoría está en el PR #14.
- **Mascota:** un pulpo. El nombre Tinta queda como propuesta, sin confirmar. Se dibujará más adelante con las mismas teselas del logo, cuadradas y redondas, para piezas grandes como la guía, los avisos y el PDF. No va en el logo ni en el ícono.
- **Interfaz:** la selección se llama «Mi mochila» y los pasos son «1. Tu clase», «2. Para todos» y «3. Para un estudiante».

Exploraciones descartadas, como registro: `opciones-logo.png` y `logo-teselas.svg` (prisma de triángulos), `tako/` (pulpo).
