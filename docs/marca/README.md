# Marca de Prizma

**Decisión del 15 de noviembre de 2026:**
- **Nombre:** Prizma.
- **Logo:** el prisma de teselas triangulares (`logo-teselas.svg`), ya usado en la cabecera y como ícono.
- **Mascota:** un pulpo. El nombre Tinta queda como propuesta, sin confirmar. Se dibujará más adelante con las mismas teselas triangulares del logo, para piezas grandes como la guía, los avisos y el PDF. No va en el logo ni en el ícono.
- **Interfaz:** la selección se llama «Mi mochila» y los pasos son «1. Tu clase», «2. Para todos» y «3. Para un estudiante».

Exploraciones descartadas, como registro: `opciones-logo.png` (prisma), `tako/` (pulpo), `mosaico/` (mosaico cuadrado y su auditoría).
