## Resumen propio

El documento reúne antecedentes migratorios, marco normativo, enfoque intercultural y orientaciones para las comunidades educativas. Aborda acceso, permanencia y avance de trayectorias educativas. En el proceso de validación contempla las barreras lingüísticas; no debe confundirse desconocer español con desconocer los contenidos.
