# Fuentes para talleres, laboratorios y terreno · Tarea 019

Fecha de consulta: **15 de noviembre de 2026**. Rama: `codex/019-fuentes-practicas`.

Se reúnen **8 fuentes: 3 chilenas y 5 internacionales**. El alcance es formación dentro del liceo o institución y terreno curricular bajo su responsabilidad. Las prácticas profesionales en empresas y los ajustes laborales quedan fuera.

Cada ficha distingue la fuente y su licencia, el material efectivamente leído, un resumen propio y localizadores. Solo se agregan archivos en esta carpeta. Los documentos completos de CNA y Subsecretaría ya estaban disponibles desde la tarea 008 y se revisaron de nuevo; el PDF didáctico de Mineduc sí se descargó en esta búsqueda. Para ASQA, DO-IT y ADCET se leyó el contenido HTML; para UNESCO, la presentación pública del libro; para Mesquita y colegas, el abstract y metadatos públicos. **No se presenta un abstract como texto completo ni una presentación como libro leído.**

## Vacíos y límites de lo encontrado

- Se encontró orientación didáctica EMTP con seguridad, simulación y equidad, pero no un manual chileno específico de ajustes por discapacidad para cada máquina o especialidad. No se afirma que no exista.
- La revisión de laboratorios encontrada permite describir el campo, no asignar porcentajes de éxito ni extrapolar directamente a IP/CFT chilenos. Su texto completo sigue pendiente.
- No se identificó evidencia específica suficiente sobre eficacia de simuladores para estudiantes con discapacidad en talleres TP chilenos. Tampoco una regla universal para ruido o tiempos de taller.
- CNA y Subsecretaría cubren inclusión institucional y formación práctica; no sustituyen el diseño técnico de medidas de seguridad de cada laboratorio.
- Se excluyeron empleo, ajustes laborales y prácticas profesionales en empresas. Las fuentes que mezclan esos ámbitos solo se usan aquí en sus secciones educativas identificadas.
