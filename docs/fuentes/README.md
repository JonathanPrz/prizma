## Documentos que faltan

Desde Prizma no se puede descargar de BCN ni de Mineduc, porque esos sitios rechazan las descargas automáticas.
Para cada documento: ábrelo, pásalo a `.md` y guárdalo con el nombre de la tabla.
Revisa que el título de la página coincida con la norma, porque el número de cada enlace se anotó de memoria.

## Reglas

- Una recomendación sin fuente no entra a Prizma.
- Las copias `.md` de normas pueden ir completas, porque son públicas.
- De los documentos con derechos reservados (CAST, OMS) se guarda solo el análisis propio, con citas cortas.
- Cada fuente se anota con su fecha de revisión.
